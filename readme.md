This webpage Currently takes either an mbl or hbl file. the file will pass though ai(currently chatgpt), in two phase. the first will determine the file type and then the second will extract the info into Json format. user can view and update the file and the json, it will also try to create or link shipment.

This project uses react js, tailwind css, and postgradsql with prisma.

Note: shipment will only be generated after the update button is clicked,shipment might have error
